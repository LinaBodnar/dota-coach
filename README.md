# Dota Coach 🛡️

Твій персональний дата-коуч для Dota 2. Слухає гру, а після кінця катки показує оцінку (S/A/B/C/D), що чотко, що не дуже і що поміняти.

🌐 **Веб-версія без встановлення:** https://dota-coach-omega.vercel.app — встав Match ID або свій Friend ID і отримай розбір.
Версія для компа (нижче) додатково слухає гру наживо (LIVE) і бачить більше деталей про смерті.

## Запуск

1. Потрібен **Node.js** (LTS з https://nodejs.org). Більше нічого ставити не треба.
2. Двічі клікни **`start.bat`**. Він:
   - знайде Доту і покладе конфіг `gamestate_integration_dotacoach.cfg` в її папку;
   - запустить сервер і відкриє http://localhost:3000.
3. Steam → Dota 2 → ПКМ → Властивості → **Параметри запуску** → додай `-gamestateintegration`.
4. Перезапусти Доту і грай. Вікно `start.bat` не закривай.

Якщо Доту не знайдено автоматично — скопіюй `gamestate_integration_dotacoach.cfg` у
`...\steamapps\common\dota 2 beta\game\dota\cfg\gamestate_integration\`

## Перевірити без гри

```
node server.js
node simulate.js
```
Симулятор «зіграє» фейкову катку на Джаггернауті за ~15 секунд.

## Файли

| Файл | Що робить |
|---|---|
| `server.js` | локальний сервер: приймає дані з Доти, зберігає катки, віддає сайт |
| `src/gsi.js` | збирає з потоку даних гри таймлайн, смерті, предмети, варди |
| `src/analyzer.js` | логіка коуча: метрики, пороги для ролей, поради |
| `src/opendota.js` | OpenDota для локального сервера: кеш довідників, бенчмарки, імпорт |
| `src/normalize.js` | перетворення матчу з OpenDota у запис катки (спільне для обох версій) |
| `public/` | інтерфейс локальної версії; `public/report.js` — малювання звіту (спільне) |
| `web/` | веб-версія для Vercel (`node scripts/build-web.js --serve` — запустити локально) |
| `data/matches/` | збережені катки (JSON) |
